## 🎬 Tips Penggunaan di Editor Video:
1. **Format SVG Vector:** Aset SVG tidak akan pecah meski di-scale hingga 4K atau 8K.
2. **Animasi Kursor:** Di After Effects / Premiere, animasikan posisi kursor menggunakan *Position Keyframes* dengan kurva *Ease In/Out* (`F9`) untuk menghasilkan efek pegas (*spring physics*).
3. **Efek Glow Tambahan:** Tambahkan efek *Gaussian Blur* (Radius 15px) dengan blending mode *Screen / Add* pada layer kursor dan garis blueprint untuk sensasi pencahayaan neon malam hari yang lebih menyala.
